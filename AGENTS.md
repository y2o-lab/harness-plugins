# Repository instructions

## Git and GitHub remotes

For this repository, use only `git` commands for repository operations involving GitHub remotes: status, fetch, pull, merge, rebase, commit, branch management, and push. Do not invoke `gh`, GitHub apps, browser automation, or GitHub APIs.

Git cannot create or modify pull requests, issues, comments, releases, or repository settings. Do not substitute another integration for those operations; ask the user for a separately authorized workflow if one is needed.
