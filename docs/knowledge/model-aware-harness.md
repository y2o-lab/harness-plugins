# モデル対応と評価

2026年11月22日時点の Codex 公式ガイドでは GPT-6.2 Astra と Sol が案内されている。利用できるモデルと推論設定はクライアントや契約によって異なる。Harness は利用者が選択したモデルで動作し、チェックの選択と合否を全モデルで共有する。[Models](https://learn.chatgpt.com/docs/models)・[Codex changelog](https://learn.chatgpt.com/docs/changelog)

開発スキルは期待する成果、制約、既存の検証方法を参照する。モデル名が判明していて追加の助言が必要なときだけ `guide --model ID` を使う。既知の Astra、Sol、Terra、Luna の ID には短い補足があり、独自プロバイダや将来の ID には共通ガイドを返す。モデル選択、推論量、会話状態、コンテキスト圧縮はホストが管理する。これらはプラグイン側の実行グラフの設定から独立している。[Prompting GPT-6.2 in Codex](https://learn.chatgpt.com/guides/prompting-gpt-6-2-astra)・[Codex as a platform](https://developers.openai.com/blog/codex-as-a-platform)

## ローカルで再現する評価

```bash
npm run harness -- verify --summary
npm run bench:harness
```

1つ目はこのリポジトリの必須テストを実行する。モデルの新旧・未登録 ID、正常系、失敗する前提、時間切れ、循環、独立したチェックの完遂、Hook の継続上限を含む。スキルの行動を評価する場合は、代表依頼に対する成果物と実行記録を別途採点する。[OpenAI のスキル評価手順](https://developers.openai.com/blog/eval-skills)

2つ目は一時ディレクトリで、各100 ms待機して1 KiBのログを返す5コマンドを実行する。ビルドは型検査とテストに依存する。全5件の名前と合格を毎回照合し、直列と並列数2の順番を交互にして5回ずつ計測する。所要時間は CLI の起動を含む。通常 JSON と `--summary` の出力バイト数も記録する。

2026年11月22日のローカル測定値（macOS arm64、Node.js v22.14.0）。

| 比較対象 | 条件 | 中央値 |
| --- | --- | ---: |
| CLI 起動から検証完了まで | 直列・要約出力 | 755 ms |
| 同上 | 並列数2・要約出力 | 462 ms |
| 結果 JSON のサイズ | 詳細出力 | 10,027 B |
| 同上 | 要約出力 | 879 B |

この測定が示すのは、独立して待機できる検証の経過時間と、成功出力を省いた場合のコンテキスト入力候補のサイズである。CPU・I/O 競合やログ量の異なる実プロジェクトには固有の測定が必要になる。モデル利用料とタスク成功率はこのベンチマークの測定対象外である。

## モデルを含む比較

実タスクで比較する場合は、同一の開始状態、依頼、モデル、推論量、利用ツール、合格条件を固定する。小変更、複数ファイルの変更、失敗からの回復を含める。成果物の受入率と誤って成功と報告した件数を先に確認し、同じ品質水準で所要時間、実行回数、ホストが報告したトークンまたはクレジットを比較する。
